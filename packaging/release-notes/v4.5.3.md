## What's new in 4.5.3

### Keys for full screen

- **New keyboard shortcuts**, set in *Settings → Shortcuts*: show or hide the latency readout (F3), start or
  stop a comparison clip (Shift+F8), and turn frame generation or AI picture enhancement on or off (no key
  until you choose one). Each says on screen what it did, so nothing needs you to leave full screen.
- Any shortcut can now be cleared, so a key you use for something else is free again.

### Remote Play

- **PS5 sound stays with the picture.** Automatic sync now uses how late each frame really is on screen and
  waits for that figure to settle before it starts the sound, and the PS5 picture clock keeps up when the
  console sends frames a little slower than it says.
- **Xbox picture resolution.** The Xbox window has a new *Picture resolution* row: Automatic (as before),
  1080p or 1440p. 1440p is asked of the console; it needs a fast, steady network.

### Fixes

- **The frame quality test works with capture cards.** It slowed the picture to a few frames a second and
  then said there were no generated frames to compare. It now runs alongside the picture as it should.
- **Frame Input: alpha is ignored.** A picture sent with alpha 0 (as many swap chains have) is shown as it
  is, instead of black.
