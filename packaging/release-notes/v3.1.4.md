## What's new in 3.1.4: your first one-click update

3.1.4 follows 3.1.3 straight away so you can try **one-click updates**:
- On 3.1.3, open PushFPS. The banner says a new version is out: click it, or go to *Settings, About* and click **Install update**.
- PushFPS downloads 3.1.4 from this page and checks the signature (RSA-3072, SHA-256), the version and the zip's hash before it replaces anything.
- It closes, installs over your current folder with the same graphics card choice, and your settings stay.

If anything doesn't match the signature, nothing is installed and you see why.

**Fixed.** In the streaming-mode layout editor, the "no picture" hint no longer runs into the box labels when nothing is connected; it now sits along the bottom edge.

**Everything from 3.1.3** is in this build: PushFlow, our own frame generation; the frame quality test and measured ranking in *Optimise for my PC*; the PS5 latency test; the layout editor and platform presets; frame input for other apps. The setup guide is attached as **PushFPS-Setup-Guide.txt**.

**How it was tested.** The same CI as 3.1.3 on Windows without a graphics card: the build, the unit tests (including the full download, signature check and install of a signed test release from a local server), the GPU tests on WARP and the install test. The real update from 3.1.3 to 3.1.4 happens for the first time on your PC: if it fails, tell us what the banner or *Settings, About* says, and download the zip from this page as before.

**Windows Defender note.** Defender may flag new PushFPS downloads as `Trojan:Win32/Tecabans.STV!cl`. This is a false positive from its cloud check on new, unsigned files, and it has been reported to Microsoft. Always check the zip against `SHA256SUMS.txt` on this page.
