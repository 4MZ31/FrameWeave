## What's new in 4.0

**Put the latency readout where you want it.** With *Show latency on screen* on, take hold of the readout
with the mouse and drag it anywhere over the picture. It stays there, also after a restart and when the
window changes size or goes full screen, and it cannot be dragged out of the picture. A double click sends
it back to the top left corner.

- While mouse input goes to the game (PS5 Remote Play, Moonlight, Xbox with the mouse captured) the readout
  is not movable: a click there belongs to the game.
- Tested so far: the interface tests (dragging, the edges, the double click, a changed window size) passed
  in a Windows test run. Not yet seen in the installed program, and not yet tried on a real capture card
  session.
